# 차곡 2.0 화면·구조 명세

한국어 iPhone 전용, iOS 18+, 계정·네트워크·iCloud 없음. SwiftUI + SwiftData + 순수 Swift 도메인 패키지.

## 화면 시안

- 오늘: 날짜 → 진행 중 타이머 → 예정 활동 카드 → 주간 자유 일정 → 완료 카드. 독서 카드는 `오늘 12쪽 / 다음 15쪽`, `페이지 기록`, `최소 5쪽 달성`. 수치는 실제 기록만 합산.
- 활동 만들기: 이름·아이콘 → 페이지/거리/시간/횟수/완료 → 1~3개 기준 → 일정 → 선택적 추가 항목. 독서 5/15/30쪽, 러닝 1/3/5km만 템플릿.
- 독서 입력: 책 선택/새 책 → 직접 분량 또는 시작·마지막 페이지 → 선택적 시간·메모. 시작 모름은 분량 미상. 다시 읽기는 새로운 구간.
- 성장: 기간 → 실제 활동량/실행률/지속력 → 활동별 차트 → 작은 XP/레벨 카드.
- 기록: 날짜·활동 필터 → 기록 → 편집/삭제. 미입력 수치는 —. 빠른 완료와 측정값을 명확히 구분.
- 설정: 활동 관리, 백업/복원, 알림, 보상 표시, 시간대. 빈 화면에 활동 추가를 안내. 오류는 복구 방법과 함께 표시.

미색 배경, 흰 카드, 초록 주요 버튼, 금색 XP. 다크 모드 시스템 색상, Dynamic Type, VoiceOver, 44pt 터치 영역. 보상은 숨길 수 있음. 저장 실패는 완료로 표시하지 않음.

## 보존

원래 웹 데이터는 Git 이력과 백업에서 복원 가능. 실제 runtime DB·이미지·백업은 삭제하지 않음. 가져오기에서 원문 전체 보존, 식사/웨이트/과외는 이전 기록 보기. 동일 ID 충돌은 명시적으로 선택. 소급 XP는 기본 꺼짐.

## 보상

활동·날짜별 실측 합산. 빠른 완료는 최소 단계만 인정, 수치 생성 없음. 10/5/5 XP, 최고 단계 이상 추가 XP 없음. 정정·삭제에 따라 재계산. 미실천 벌점 없음. 일일 기준 변경 다음 날, 주간 변경 다음 월요일. 부분 첫 주는 실패로 확정하지 않음.

## 2026-10-17 화면 다듬기
- 따뜻한 미색 바탕, 동적 초록 강조색, 흰색/다크 대응 표면을 유지한다.
- 공통 카드는 모서리 24pt, 내부 여백 20pt, 얇은 경계와 약한 그림자로 구분한다.
- 활동 아이콘은 44pt 타일로 통일하며 장식 아이콘은 VoiceOver에서 제외한다.
- 오늘·성장의 주요 제목은 Dynamic Type을 따르는 rounded largeTitle을 사용한다.
- 오늘 XP 요약은 은은한 초록·금색 배경으로 구분하고 실제 활동 카드의 버튼은 기존 순서를 유지한다.
- 체크포인트는 실제 달성 단계만 분절 막대로 채운다. 막대의 VoiceOver 설명은 달성 단계/전체 단계이며 미상 수치를 추정하지 않는다.
- 온보딩과 기록·성장 화면에도 같은 아이콘·카드 체계를 적용한다. 데이터 모델·보상 계산·저장 형식은 변경하지 않는다.

## 활동 설정과 단위 입력
- 기존 활동은 읽기 전용으로 열고 편집 버튼 후에만 설정·추가 항목·삭제를 조작한다. 신규 활동은 바로 입력한다.
- 단계 기준은 1·2·3단계 각각 별도 입력란과 오른쪽 단위를 사용한다. 1단계 필수, 나머지는 연속된 선택 단계이며 오름차순 검증을 유지한다.
- 수치 입력은 UnitInput으로 통일한다. 페이지·시간·거리·러닝 상세·사용자 정의 단위·주간 일수·반복 간격을 포함한다.
- 아이콘 모양 28개와 색상 6개를 선택하며, 활동에 선택 색상을 보관한다. 색상이 없는 기존 데이터는 기본 초록으로 표시한다.
- 삭제는 확인 후 활동과 연결 기록·XP·타이머를 제거하고 예약 알림을 취소한다. 책과 첨부 파일, 이전 원문은 보존한다. 기록을 보존할 때는 기존 활동 보관을 사용한다.

## 색상 미리보기·활동 알림·기록 동작
- 색상은 현재 아이콘 모양의 여섯 미리보기에서 선택한다. 체크 표시와 VoiceOver 선택 상태를 함께 제공한다.
- 활동별 알림 켜기/끄기와 시각은 활동 편집 화면에 둔다. 시각은 활동 모델에 저장되어 JSON/ZIP 백업에 포함된다.
- 설정의 전체 알림 스위치는 기기별 설정이다. 끄더라도 활동별 시각을 지우지 않는다. 켜면 허용된 권한 범위에서 재예약한다.
- 저장·앱 복귀 시 향후 28일의 가까운 알림부터 최대 60개를 예약한다. 주 N회는 월요일 안내이며, 보관 활동은 제외한다. 기존 예약 시각은 첫 실행에 활동 설정으로 이전한다.
- 기록 행의 수정 버튼은 해당 기록을 바로 연다. 수정 화면에서 삭제 취소/확정을 제공하고 저장 성공 후에만 닫는다.

## 추가 사용성 피드백
- 설정의 새 활동 여부를 별도 화면 상태 대신 저장된 활동 ID 존재 여부로 판단한다. 저장 검증 오류는 하단 문구 대신 즉시 알림창으로 표시한다.
- 완료형은 1회 기준만 보여 주고 수정 불가로 한다. 단계별 횟수 목표는 횟수 측정으로 구성한다.
- 기록의 수정 버튼은 날짜 바로 아래에 배치한다.
- 오늘의 격려 문구와 성장 화면의 중복 제목을 제거한다. 둥근 시스템 글꼴 디자인, 가벼운 제목 굵기, 캡슐 버튼과 얕은 카드 그림자를 사용한다. 한글은 시스템이 지원하는 글리프로 렌더링되며 외부 폰트 의존성은 추가하지 않는다.
