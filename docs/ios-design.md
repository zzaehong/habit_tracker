# 차곡 2.0 화면·구조 명세

한국어 iPhone 전용, iOS 18+, 계정·네트워크·iCloud 없음. SwiftUI + SwiftData + 순수 Swift 도메인 패키지.

## 화면 시안

- 오늘: 날짜 → 진행 중 타이머 → 예정 활동 카드 → 주간 자유 일정 → 완료 카드. 독서 카드는 `오늘 12쪽 / 다음 15쪽`, `페이지 기록`, `최소 5쪽 달성`. 수치는 실제 기록만 합산.
- 활동 만들기: 이름·아이콘 → 페이지/거리/시간/횟수/완료 → 1~3개 기준 → 일정 → 선택적 추가 항목. 독서 5/15/30쪽, 러닝 1/3/5km만 템플릿.
- 독서 입력: 책 선택/새 책 → 직접 분량 또는 시작·마지막 페이지 → 선택적 시간·메모. 시작 모름은 분량 미상. 다시 읽기는 새로운 구간.
- 성장: 기간 → 실제 활동량/실행률/지속력 → 활동별 차트 → 작은 XP/레벨 카드.
- 기록: 날짜·활동 필터 → 기록 → 편집/삭제. 미입력 수치는 —. 빠른 완료와 측정값을 명확히 구분.
- 설정: 활동 관리, 백업/복원, 알림, 보상 표시, 시간대. 빈 화면에 활동 추가를 안내. 오류는 복구 방법과 함께 표시.

미색 배경, 흰 카드, 초록 주요 버튼, 금색 XP. 다크 모드 시스템 색상, Dynamic Type, VoiceOver, 44pt 터치 영역. 보상은 숨길 수 있음. 저장 실패는 완료로 표시하지 않음.

## 보존

원래 웹 데이터는 Git 이력과 백업에서 복원 가능. 실제 runtime DB·이미지·백업은 삭제하지 않음. 가져오기에서 원문 전체 보존, 식사/웨이트/과외는 이전 기록 보기. 동일 ID 충돌은 명시적으로 선택. 소급 XP는 기본 꺼짐.

## 보상

활동·날짜별 실측 합산. 빠른 완료는 최소 단계만 인정, 수치 생성 없음. 10/5/5 XP, 최고 단계 이상 추가 XP 없음. 정정·삭제에 따라 재계산. 미실천 벌점 없음. 일일 기준 변경 다음 날, 주간 변경 다음 월요일. 부분 첫 주는 실패로 확정하지 않음.
