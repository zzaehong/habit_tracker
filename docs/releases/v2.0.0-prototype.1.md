# 차곡 2.0 — 첫 iPhone 프로토타입

GitHub 소스 프리릴리스입니다. iPhone 설치 파일(IPA), TestFlight, App Store 배포는 포함하지 않습니다.

## 포함한 기능
- SwiftUI·iOS 18+의 오프라인 iPhone 앱, SwiftData 기기 저장.
- 독서·러닝 템플릿 및 페이지·거리·시간·횟수·완료 기반 커스텀 활동.
- 단계별 체크포인트, 빠른 완료, 타이머, XP·레벨과 실제 활동량·실행률·지속력.
- 아이콘 모양·색상 미리보기, 명시적 편집 모드, 활동 삭제 및 기록 수정·삭제.
- 활동별 로컬 알림과 전체 알림 스위치.
- JSON·이미지 ZIP 백업/복원, 기존 웹 백업 이전, 기기 내 NRC OCR.
- 한국어 UI, 큰 글자·다크 모드, 둥근 카드와 버튼.

## 실행
1. 이 태그의 소스 ZIP을 내려받아 압축을 풉니다.
2. Xcode에서 ios/Chagok.xcodeproj를 엽니다.
3. Chagok scheme과 iPhone Simulator를 선택해 실행합니다.
4. 실제 iPhone 실행은 본인의 Apple 서명 Team과 Bundle Identifier 설정이 필요합니다.

앱 표시 버전은 2.0.0, 빌드 번호는 1입니다. 프로토타입 구분은 Git 태그에 표시합니다.
계정·서버·iCloud 동기화는 없습니다. 중요한 기록은 설정에서 이미지 포함 ZIP으로 백업하세요.

## 검증과 제약
릴리스 브랜치에서 핵심 테스트 20개, iPhone 시뮬레이터 UI 테스트 8개, iPhone Release 빌드가 통과했습니다. 상세 기록은 docs/validation.md를 참고하세요.
- 실제 iPhone, iOS 18 런타임, VoiceOver 음성, 실제 NRC 캡처 정확도는 검증 완료로 간주하지 않습니다.
- 알림 실제 전달·권한 거절·기존 예약 이전의 실기기 검증은 미수행입니다.
- 알림은 앱 실행·복귀 시 향후 28일의 가까운 일정부터 최대 60개를 예약합니다. 오랫동안 앱을 열지 않으면 이후 알림은 예약되지 않습니다.
- 소스에 개인 기록·이미지·백업·서명 인증서는 포함하지 않습니다.
- 기존 웹·Node 서버는 현재 소스에서 제거했으며 Git 이력으로만 보존합니다.
