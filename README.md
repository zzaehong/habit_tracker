# 차곡 — 로컬 중심 습관·활동 기록

아이폰과 맥에서 사용하는 개인 PWA입니다. 기기에 먼저 저장하고 맥미니에 연결되면 동기화합니다. 서버는 잠자기를 방해하지 않으며, 인터넷 호스팅이나 유료 AI API가 필요하지 않습니다.

## 시작

Node.js 24 이상과 npm이 필요합니다.

```sh
npm ci
npm run build
npm run server
```

맥에서 http://127.0.0.1:8787 에 접속합니다. 기록은 연결 전에도 사용할 수 있습니다. 실제 두 기기 사용은 **동일한 Tailscale HTTPS 주소**를 사용하세요. localhost, IP, HTTPS 주소는 브라우저 저장소가 서로 다릅니다.

새 터미널에서 다음 명령으로 10분 동안 유효한 일회용 기기 코드를 만듭니다.

```sh
npm run pair
```

앱의 **설정 → 기기 연결**에서 코드를 입력합니다. 각 기기마다 새 코드를 발급합니다. 서버는 `127.0.0.1`에만 바인딩하며 기기별 인증 토큰으로 API 접근을 제한합니다.

## 아이폰과 연결

1. 맥·아이폰에 Tailscale을 설치하고 같은 개인 계정으로 로그인합니다.
2. 맥에서 `tailscale serve --bg http://127.0.0.1:8787`을 실행하고 안내에 따라 HTTPS를 활성화합니다. 공개 인터넷에 여는 Funnel은 사용하지 않습니다.
3. 표시된 `https://…ts.net` 주소를 맥과 아이폰에서 모두 사용합니다.
4. 아이폰 Safari의 공유 메뉴에서 **홈 화면에 추가**합니다. 최초 로딩과 기기 연결은 맥이 깨어 있을 때 합니다.
5. 맥이 잠들면 로컬 기록만 저장합니다. 맥이 깨어 있고 앱을 열거나 돌아왔을 때 자동 동기화합니다.

닫힌 아이폰 앱에서의 동기화는 보장하지 않습니다. 브라우저 저장소를 삭제하면 아직 동기화하지 않은 기록이 사라집니다. 백업과 마지막 동기화 시각을 확인하세요.

## 기록 기능

- **독서:** 책·페이지·시간·메모. 이전 페이지를 바탕으로 분량 계산.
- **러닝:** 거리·시간·체감 강도·심박수·케이던스·계산 페이스, NRC 캡처 분석.
- **웨이트:** 운동별 세트·kg·횟수, 이전 루틴 복사.
- **식사:** 에피타이저·아침·점심·저녁 고정 식단, 영양소 총량, 식사 시간, 외식·거름·추가 음식.
- **과외:** 대상 별칭·과목·예정/실제 시간·내용.
- **공부:** 과목·시간·메모·타이머.
- 숫자·텍스트·단일 선택 추가 항목과 유연한 반복 일정.
- 기간별 조회·집계, JSON/CSV/이미지 포함 ZIP 내보내기와 복원.

누락 수치는 0이 아닙니다. 외식 영양소를 입력하지 않으면 알려진 영양소만 합산합니다. 고정 식단 변경은 과거 식사의 수치를 바꾸지 않습니다. 동시 수정은 설정의 확인 목록에서 두 내용을 비교해 선택합니다.

## 로컬 AI와 NRC 캡처

Ollama 설치 후 맥에서 실행합니다.

```sh
ollama pull qwen3:4b
ollama serve
```

Ollama 앱이 이미 실행 중이면 `serve`를 중복 실행하지 않습니다. **설정 → 로컬 AI**에서 연결 확인과 모델 변경이 가능합니다. 원문은 먼저 저장되며 모델이 없어도 수동 기록은 계속 사용할 수 있습니다. 결과는 확인 후에만 활동 기록에 반영합니다.

macOS Command Line Tools가 설치되어 있다면 OCR 도구를 빌드합니다.

```sh
npm run ocr:build
```

러닝 상세 입력에서 PNG/JPEG 캡처를 최대 5장, 장당 10MB까지 업로드합니다. macOS Vision이 로컬에서 문자를 인식합니다. 실제 캡처에 없는 값은 채우지 않으며 충돌·불확실한 수치는 확인해야 합니다. 그래프 시계열 복원은 지원하지 않습니다. OCR 원본은 기본 보관하며 개별 삭제 가능합니다.

## 자동 시작·백업·복원

[운영 안내](docs/operations.md)에 LaunchAgent 설치, 자동 백업, 서버 전체 복원, 업데이트 절차가 있습니다. 런타임 기본 경로는 `runtime/`이며 `DATA_DIR` 환경 변수로 변경할 수 있습니다. Git에는 실제 기록·이미지·토큰·백업을 넣지 않습니다.

## 검증

```sh
npm run check
PLAYWRIGHT_BROWSERS_PATH=runtime/browsers npx playwright install chromium
PLAYWRIGHT_BROWSERS_PATH=runtime/browsers npm run test:e2e
npm run evaluate:ai
```

`check`는 단위·통합 테스트, 타입 검사, 프로덕션 빌드를 수행합니다. E2E는 독립된 테스트 서버를 사용합니다. 실제 모델 평가는 Ollama가 필요하고 구조 검증 결과와 의미 정확도 검토를 구분합니다.
